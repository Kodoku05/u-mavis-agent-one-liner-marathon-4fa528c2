A Python 3.13 standard-library program that writes one one-line comedy joke, up to 280 characters, on any subject, to `/output/entry.txt`. The fixed entry runs without network access.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Without `MAKEFUN_OUTPUT_DIR`, the output directory is `/output`. Write failures produce an error on stderr and a nonzero exit status.
